怎么做出简单又好吃的红烧鸡腿，家常做法

看正文 · 557 字
第一次做红烧鸡腿我就差点栽在炒糖色上，锅底糖一冒小泡我愣神，回头就糊了，整锅带苦味。后来才摸到门道：糖色想炒好，火小了什么都好说。先跟你们讲怎么下手，真的不难。 鸡腿洗干净先在表面划两刀，入味更快。冷水下锅，扔几片姜、倒一勺料酒焯水，水开后撇掉浮沫，捞出来用温水冲净。这一步别偷懒，血沫慢慢析出来，腥味基本就没了，热水下锅反而把腥味锁在肉里。 接下来是给鸡腿上色的关键。锅里少放点油，丢几块冰糖，全程小火慢慢熬，糖化成枣红色、冒出细密小泡的时候，赶紧把鸡腿倒进去翻炒，让每块都裹匀。糖色最容易翻车，颜色一到就得下肉，别犹豫。不敢炒的话就用老抽顶上，下鸡腿后直接加生抽老抽和冰糖，颜色照样红亮，就是少了点焦糖香，新手这么来更稳。鸡腿我一般选琵琶腿，肉厚耐炖；整只炖出来更嫩，看你自己。 然后放葱段姜片、八角桂皮，淋生抽老抽和料酒，炒出香味，倒热水没过鸡腿，加盐调味，大火烧开转小火，盖盖子炖二十分钟上下。中途翻一次让它入味，筷子能轻松扎透、不见血水就熟了，肉厚就多几分钟。 汤汁收浓那一步最考验耐心：开大火边收边翻，看着它变浓稠挂到鸡腿上，红亮油润，特别下饭。爱软烂就多炖十分钟。收汁这阵子人别走开，一转身就糊底。 出锅别提多香了，烫嘴也等不及夹一块，肉软嫩到筷子一碰就散，把汤汁淋在米饭上，我能多吃一碗。

小白鞋发黄怎么洗，关键在晾晒不在洗

看正文 · 440 字
小白鞋一洗就发黄，我一开始以为是没洗干净，后来才发现问题出在晾晒上。暴晒加残留的洗涤剂，才是鞋面泛黄的元凶，洗得再用力也没用。 清洗时先用软毛刷蘸清水把浮灰刷掉，局部发黄的地方挤点白色牙膏，用旧牙刷打圈刷，再拿湿布擦净，牙膏里的研磨成分对帆布和网面特别管用。网面刷的时候动作轻点，别把网眼刷破。顽固黄渍可以试试小苏打加白醋调成糊，敷十几分钟再刷。皮面就别用牙膏硬刷了，换中性清洁剂和软布，免得伤涂层。 最关键的还是晾晒。千万别放太阳底下暴晒，紫外线一晒氧化更快，鞋面更黄。正确做法是冲净挤干后，用白色纸巾把整只鞋包严实，放通风阴凉处晾干，纸巾会把残留的洗涤剂和水分吸走，鞋干后纸巾发黄、鞋面却白净。没纸巾就用干净的白色棉布，别用彩色或有图案的，颜色会染上去。 鞋边和橡胶底发黄，用小苏打糊或专用橡胶清洁剂刷，刷完照样冲净阴干。日常穿完及时擦掉污渍、别让鞋长期泡水、别和深色衣服一起洗，能少很多麻烦。要是黄渍已经渗进纤维洗不掉，就交给专业洗鞋剂或洗鞋店吧。记住，洗得干净不如晾得对。

羊毛衫缩水怎么处理？温水护发素拉伸法

看正文 · 557 字
羊毛衫洗缩水，从M变成XS，多半是扔进洗衣机搅出来的。羊毛纤维表面有鳞片，在湿热和反复摩擦下会互相纠缠、毡化，越好的料子缩得越明显。已经缩水的羊毛衫能不能救，关键看缩得严不严重，轻微到中度的可以自己处理。 最常用的方法是温水护发素法。准备一盆温水，加入护发素，护发素和水按1比3的比例搅匀，把缩水的羊毛衫放进去浸泡10到15分钟。护发素能软化纤维、减少摩擦，让纠缠的鳞片松开。浸泡时轻轻揉搓并顺势拉伸，取出后不要拧，用挤压的方式把水挤掉。 趁羊毛衫还湿润，把它平铺在一条干浴巾上，用浴巾卷起来，边挤压边卷，反复几次吸走水分。然后趁湿润状态轻轻把羊毛衫拉伸到合适尺寸，平铺在晾衣篮里阴凉处晾干。全程不要用手拧绞，也不要挂衣架晾，否则会变形。晾干过程中不要暴晒，会损伤纤维。 如果缩水比较严重，可以试试白醋法。在温水中加少量白醋，把羊毛衫浸泡30分钟，取出后轻轻拉扯，再平铺晾干。白醋能软化毛料，让紧缩的纤维变蓬松。也可以用蒸汽熨斗加热后趁热拉伸，但力度不好掌握，容易拉过头。 需要提醒的是，缩水特别严重、已经明显毡化的羊毛衫，很难完全恢复原样，市面上那些复原剂本质也是柔顺剂，效果有限。与其事后补救，不如平时注意护理：用羊毛专用洗涤剂，水温控制在30℃以下，单独手洗，轻按不要揉搓，漂洗后挤压水分，平铺阴干。

除了步行骑车公交，还有哪些值得倡导的出行方式？

看正文 · 536 字
以前我总觉得，不开车就只能挤公交，直到有次赶早高峰，地铁口到公司那两公里，走路嫌慢、打车又堵，最后扫了辆共享单车，十分钟就到，还出了一身汗，反而清醒。从那以后我才发现，值得倡导的出行方式其实不少，核心就一句：能少开车就少开车，能拼着走就拼着走。 短途接驳，共享单车和共享电单车是真香。一两公里这种最后一公里，从地铁站到家、从公交站到公司，骑车比走路省时间，又比开车低碳，还不用等车。我每次下班懒得走那一段，扫一辆骑回去，风一吹整个人都松快。记得规范停放，别乱停占道，这也是绿色出行的一部分。 中短途，电动自行车和拼车顺风车都值得试。三五公里通勤，电动车灵活又省力，堵车也不怕；拼车顺风车把一辆车多个人坐，人均排放低不少，适合路线固定、顺路的人。我同事每天拼车上下班，说既省钱又不孤单。拼车记得选正规平台，确认好行程和费用，安全第一。 中短途出行，高铁通常比自驾和飞机更低碳，点对点时间可控，还省去停车堵车的麻烦。能坐高铁，就不必非要开车或坐飞机。其实还有一种更省事的，就是减少不必要的出行。能远程办公、线上办事、网上买菜就线上解决，把出门次数降下来，本身就是最直接的低碳。 说到底，值得倡导的不是某一种方式，而是按距离选最合适的、能共享就共享、能少走就少走的习惯。
