# 历史类比镜

## 概述

用户说出自己的困境后，本技能沿**中国与国际全部历史纵深**（先秦到当代，不设下限）检索处境相似的知名人物，
对每个人做**三层取证**：

| 层 | 问的问题 | 证据类型 | 常见陷阱 |
|---|---|---|---|
| **L1 当时行为** | 他实际上做了什么？ | 同时代文献、档案、书信、实录、当事人的同时代记录 | 把成功归因于个人品格，忽略结构性条件 |
| **L2 当时自述** | 他当时如何解释自己的动机？ | 奏疏、家书、诗文、日记、自序 | 修辞性自辩，被采信为事实 |
| **L3 后世诠释** | 后来人/他自己如何讲述这段经历？ | 史书评价、传记、后人研究、自传、纪念文字 | 英雄神话、道德教化加工 |

**核心洞见：L1 与 L2/L3 的落差本身就是最有价值的信息。**
一个人在低谷时说"我从未动摇"和他在低谷时实际写下的"我夜不能寐"之间的差距，
往往比任何一条结论都更能回答用户的问题 —— 因为那揭示了**人如何给自己讲一个能继续走下去的故事**。

## 与 case-finder 的边界（必须分清）

| | case-finder | **本技能** |
|---|---|---|
| 取材范围 | 当代商业案例，联网可查 | 全部历史，纵深不限 |
| 对象 | 公司为主 | **人**为主 |
| 组织方式 | 好结果 / 坏结果二分 | **L1 行为 / L2 自述 / L3 后世诠释** 三层 |
| 落点 | 具体解决办法 | 处境类比 + 叙事落差 + 启示 |
| 人物是否需真实 | 必须真实 | 必须真实，**且需标注史料强度** |

用户描述困境时两者可能都有用：先用本技能找**处境可比的人**，
若用户要的是"现在这事该怎么做"，再补 case-finder 找当代可执行案例。

## 工作流程

### 第零步：把困境翻译成「处境原型」（最关键，最易草率）

不要直接拿用户原话去搜。先抽象出**结构性处境**，因为史料里可匹配的是处境而非字面。
按**六轴**拆解（详见 `references/困境原型库.md`）：

1. **位置轴** —— 他所处的位置：新手 / 掌权者 / 边缘人 / 中间层 / 已出局
2. **压力轴** —— 压力的来源与期限：资源枯竭 / 权力博弈 / 道德两难 / 认知颠覆 / 关系决裂 / 意义丧失
3. **期限轴** —— 决策窗口还剩多久：一夜 / 一个周期 / 一生 / 一时代
4. **选择权轴** —— 还能选什么：可逆且可退 / 不可逆但可止损 / 已被剥夺
5. **关系轴** —— 冲突方向：对上 / 对下 / 对平级 / 对市场 / 对自己
6. **认知轴** —— 真相是否已被知道：已知 / 已知但不愿承认 / 尚未察觉

输出一句**处境白描**给用户确认（例：「你不是"没考上"，你是"在报名截止前 3 小时发现核心前提被推翻，
且不可逆，但可以止损」）。白描错了，后面全错 —— 宁可多问一轮。

### 第一步：分轨检索（中外并行，双向搜）

必须**中英双语各跑**，且刻意跨越三个时代带，避免只搜到"最近的著名商业人物"：

```bash
# 检索矩阵 —— 每个轴都要换词
WebSearch "<处境白描关键词> 历史人物"                      # 中文轨道
WebSearch "<situation keywords> historical figure who"    # 英文轨道
WebSearch "<处境白描> 古人 如何自处"                        # 中国古典
WebSearch "<处境白描> 传记 评价 争议"                      # 找 L3 诠释与争议
```

**候选池要求**（详见 `references/人物候选池.md`，含按原型索引的约 120 人）：
- 中外各 ≥ 3 人，跨 ≥ 2 个时代带（古典 / 近现代 / 当代）
- 至少 1 人**结局不佳**（只给成功案例是幸存者偏差，是本技能的头号失效模式）
- 至少 1 人当时处境**与用户权力位置相反**（下属视角 vs 决策者视角）

### 第二步：三层取证（逐人执行，不可跳过 L1）

对每个候选人执行（详见 `references/史料分级与取证.md`）：

**L1 当时行为** —— 找到当时的**具体动作与时间点**：做了什么、什么时间、代价是什么。
- 必须能回答："他**具体**做了哪几件事？" 而不是"他选择了坚持"。
- ⚠️ **幸存者偏差拆解**：这个人成功/失败，有多少是他的判断，有多少是时代给的？
  必须显式区分 `个人可控变量` vs `时代给的红利/劫难`。

**L2 当时自述** —— 他自己怎么说。找**带日期的原话**（书信、奏疏、奏折、日记、诗句）。
- 优先引原文（文言引原文 + 白话翻译），不引二手转述。
- ⚠️ 战时奏疏、狱中书信、临终遗言都是**有特定受众的修辞**，不是内心独白 —— 引用时说明这一点。

**L3 后世诠释** —— 后人怎么讲这段：正史评价、野史轶闻、20 世纪史家重评、当代传记、纪念文章。
- 特别关注**评价的分歧**。存在争议本身就是信息。
- ⚠️ **警惕"盖棺定论"**：《明史》对某人的定评可能是修《明史》那个时代的政治需要，不是史实。

**落差检验（本技能的招牌步骤，务必做）**：
显式写出 L2/L3 与 L1 之间的落差，并回答：
- 这个落差是**当时的处境所迫**（身不由己）还是**事后的自我合理化**（自辩）？
- 如果他当时**如实说**了同样的内容，代价会不会更高？
- 他讲给自己听的故事，讲给别人听的故事，讲给历史的故事，是同一个吗？

### 第三步：输出（严格按结构，见 `references/输出模板.md`）

结构固定为：
1. **你的处境白描**（先让用户确认对象找对了没）
2. **横向对照表**（一眼看清：谁 / 什么处境 / 当时做了什么 / 后来怎么讲 / 结局）
3. **逐人详解**（每人必含 L1/L2/L3 + 落差 + 对你的启示 + 史料强度标注）
4. **反差最大的三个人**（把落差最大的拎出来单独说 —— 这部分通常是全文最有价值的）
5. **他们没说出口的共同结构**（跨人物的规律，这才是"规律"而非"鸡汤"）
6. **不适合你的那部分**（诚实说明哪个类比不成立、会被误导的地方）
7. **出处清单**（可独立查证的关键词/书名/篇名）

## 铁律

### 一、真实性铁律
1. **人物必须真实存在**，且经历与所述处境确实对得上。不许编造史料、不许张冠李戴。
2. **引文必须可查证**。引不到原话就说"未找到直接引文，现有记载为……"，绝不编造看似精确的句子。
3. **不确定就标注不确定**。允许写"以下为学界两种说法，我无法判定" —— 这比假装确定有用得多。
4. **每人的资料标注来源类型**：一手史料 / 史家研究 / 通俗读物 / 网络说法，并**标明可信度**。

### 二、双层铁律（这是本技能区别于 case-finder 的核心）
5. **L1 与 L2/L3 必须分开写，不许合并成一句"他选择了坚持并乐观面对"**。
   那种话是把 L1 和 L3 揉在一起的伪叙述，是本技能的头号失效模式。
6. **必须做落差检验**。L1 与 L2/L3 高度一致的案例（罕见的）也要写明"未发现明显落差"，
   不能因为找不到落差就跳过这一步。

### 三、反偏差铁律
7. **必须包含失败案例**。全是成功案例 = 幸存者偏差，直接作废。
8. **必须做时代归因**。把"生于乱世"当成个人勇气，是把结构问题个人化的谬误。
9. **警惕时代错置**。不把现代价值观直接套在古人身上（如用"内耗""情绪价值"描述明代人的心理）；
   遇到这类概念错位，明确指出"古人没有这个概念，最接近的是……"
10. **拒绝鸡汤**。"他们都在困境中成长为传奇"这类句子一律不写。
    要写具体代价：失去了什么、付出了什么、多久才缓过来。

### 四、边界铁律
11. **不诊断、不揣测用户心理**。历史类比用于照见处境，不用于评判用户的人格或推断其精神状态。
    涉及持续的情绪困扰时，提示"历史类比不能替代专业帮助"，不越位。
12. **不把类比当建议**。明确区分「他当时面临的历史条件」与「你现在的条件」，
    指出哪些不可比（见输出第 6 节"不适合你的那部分"）。历史不能直接当行动指南。

## 常见失效模式（自查）

| 失效 | 现象 | 对策 |
|---|---|---|
| **字面匹配** | 拿用户原话去搜，搜出表面相似实则处境不同的案例 | 先做处境白描再检索 |
| **成功者偏差** | 找到的全是"坚持到最后"的成功者 | 强制加入失败与中途退出者 |
| **叙事缝合** | 把零散记载拼成流畅故事，细节其实是编的 | 每个细节能问出出处，问不出就删 |
| **L1/L3 混同** | "他坚韧不拔地走了下去" | 拆成 L1（做了什么）与 L3（后人怎么讲） |
| **时代归因过载** | 把成功全归于个人 | 显式列出时代红利与个人变量 |
| **古今概念错置** | 用"职场内耗"描述唐代人 | 标注概念边界，给最接近的历史概念 |
| **鸡汤化** | 结尾变成"你也能像他们一样" | 结尾只给结构洞察，不给保证 |
| **只搜中文** | 搜到的全是中国人，用户要的是"中国和国际" | 中英双语各跑一轮，并明示覆盖 |
| **时代带过窄** | 全是近现代人 | 强制跨至少两个时代带 |
