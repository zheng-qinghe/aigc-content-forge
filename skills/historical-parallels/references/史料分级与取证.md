# 史料分级与取证

> 用途：让 L1 / L2 / L3 三层各有对应的取证方法，并标清每条信息能信到什么程度。
> 核心是**先定证据等级，再写结论** —— 顺序反了就会用小说家的写法冒充史学。

---

## 三层取证定义

| 层 | 定义 | 时间点 | 典型证据 |
|---|---|---|---|
| **L1 当时行为** | 他实际上做的事：动作、时间、代价 | 事件发生时 | 档案、实录、账目、同时代人的记录、实物 |
| **L2 当时自述** | 他当时对自己行为的解释 | 事件当时（稍后亦可） | 书信、奏疏、奏折、日记、诗文、题跋 |
| **L3 后世诠释** | 后人（含他自己晚年）如何讲述这段 | 事后 | 史书论赞、传记、后世研究、自传、纪念文字、口述史 |

**为什么必须分开**：三者会互相冲突。冲突本身是最有价值的信息。
把它们揉成一句"他从容不迫地坚持了下来"，等于把 L1 的事实和 L3 的修辞混为一谈。

---

## 取证顺序（严格按此执行）

### Step 1 — 先找 L1，再找 L2，最后找 L3

多数人查历史会直接从 L3 入手（因为 L3 好找、有故事、有金句）。
**这是本技能最常见的错误路径**：先读了一篇感人的传记故事，再去确认事实，
结果整篇分析都在为一个不准确的叙事服务。

**正确顺序**：L1 定骨架 → L2 补动机 → L3 看落差。顺序不可颠倒。

### Step 2 — 给每条信息标等级

| 等级 | 类型 | 可信度 | 用法 |
|---|---|---|---|
| **A** | 当时的档案、账目、官方记录、当事人同时代书信 | 高 | 可作为事实陈述 |
| **B** | 同时代第三人的记述（如同事的回忆录） | 中 | 需与其他材料交叉验证 |
| **C** | 后世史家的研究（有考据、有引用） | 中高 | 可作事实框架，重要处需回溯其所引原始材料 |
| **D** | 后世通俗读物、评书、影视改编、网文 | 低 | **只作线索，不作依据**，且必须在输出中标注 |
| **E** | 无出处的"据说/相传" | 极低 | 不可用，或明确标为"仅传说" |

**输出时的标注方式**：
> 〔B〕王阳明在龙场驿的书信中提到……
> 〔D〕某通俗读物称他"三年不发愤"，此说未见于其本人文字，仅作参考。

### Step 3 — 逐人填写"取证状态表"

在内部（不必全输出）先填这张表，避免写到一半发现关键层缺证据：

| 检查项 | 有/无 | 备注 |
|---|---|---|
| L1：他具体做了什么？有时间点吗？ | | 无 → 换人 |
| L1：代价是什么？（失去的具体东西） | | 无 → 缺关键维度 |
| L2：有带日期的原话吗？ | | 无 → 只能写 L1/L3，需说明 |
| L3：后人的评价有分歧吗？ | | 无 → 可能查得不深 |
| 落差：L2/L3 与 L1 有冲突吗？ | | 无 → 也要明写"未发现明显落差" |
| 归因：时代给的条件是什么？ | | 无 → 必做个人归因谬误 |

## 各层的取证要点

### L1 当时行为 —— 找动作，不找形容词

必须能回答「他**具体**做了哪几件事」。

- ❌ 不合格：「他坚韧不拔地坚持了三年」
- ✅ 合格：「他连续三年每天只睡两个时辰，遣散了八成幕僚，把全部田产抵押出去筹措军资（〔A〕《明实录·太宗实录》卷某）」

**追问清单**：
1. 他做的第一个具体动作是什么？时间、地点？
2. 他**放弃**了什么？（放弃的东西比坚持的东西更能说明处境）
3. 他找谁求助了？谁拒绝了他？
4. 事后看，这个动作当时合理吗？（在当时的信息条件下判断，不用后见之明）

### L2 当时自述 —— 引原文，且说明修辞场合

**优先引原文**（文言引原文 + 白话翻译），不引二手转述。

⚠️ **关键警告：几乎所有 L2 材料都有修辞目的。**
战时奏疏是给皇帝看战略决心；狱中书信是给家人看意志坚定；临终遗言是做身后安排。
**它们不是内心独白**。引用时必须说明：

> 〔A〕他在狱中给家人的信中写"……"（白话：……）
> ——注意：这是**写给家人的信**，有明确的安抚与表态功能，
> 不宜直接当作他当时的心理实况。

**好的 L2 往往不是"我永不放弃"这类宣言，而是有具体内容的**：
- 抱怨具体的人、具体的事、具体的恐惧
- 对自己判断的复盘（"我以为……，结果……"）
- 当时的实用打算（"若……则……"）

这三类比金句有价值得多。

### L3 后世诠释 —— 找分歧，不找定论

**特别关注评价的分歧**：

| 分歧类型 | 意义 |
|---|---|
| 同时代 vs 百年后 | 后世评价常随时代价值观变化（如对商人的评价） |
| 官方史书 vs 野史 | 官方史书受修史者所处政治环境影响 |
| 敌对方 vs 本方 | 双方记述往往互相矛盾，都要看 |
| 20 世纪史家 vs 传统叙事 | 近代史学常有重大翻案 |

**警惕盖棺定论**：
> 〔C〕《明史》对其评价为"刚愎自用，不听善言"，
> 但〔C〕现代史家王某某指出，此评形成于清修《明史》时期，
> 反映的是清初对前明的政治定性，**不等于对其当时处境的公允判断**。

## 常见伪史料与陷阱

| 陷阱 | 表现 | 防御 |
|---|---|---|
| **语出后人** | 归给某人的名言，其实晚出百年 | 追问"最早出处在哪"，找不到就标为"后人托名" |
| **层层转述** | A 记的事来自 B，B 来自 C，C 来自 D（同时代人的传闻） | 追到最早的现存文本，否则降级 |
| **时代错置** | 用现代概念描述古人（"内耗""情绪价值""职场 PUA"） | 标注概念边界，给最接近的历史概念 |
| **生存者偏差** | 留下来的都是成功者的记录 | 主动找失败的、被遗忘的、同时代失败者 |
| **结果论** | 因为他成功了，就说当时的决策是英明的 | 明确区分"当时合理"与"事后正确" |
| **以讹传讹** | 广泛流传但无一手依据的说法 | 查是否有 A/B 级依据；无则标 D/E |
| **金句幻觉** | 记忆里"他有一句名言"，实际查不到 | **查不到就绝不写**。宁可说"未找到直接引文" |

> ⚠️ **金句幻觉是 AI 做历史类比的头号事故。**
> 模型对名人的熟悉度很高，容易"记得"一句漂亮的话并顺口写出。
> **铁律：任何带引号的直接引语，必须能指出出处（书名/篇名/卷次/信件名）。**
> 指不出出处的引语，一律删除或改为间接转述并标注"未找到直接引文"。

## 时代归因：把结构与个人分开

每个案例必做这个切分：

| 类别 | 内容 |
|---|---|
| **个人可控变量** | 当时的判断、选择、动作、争取来的资源 |
| **时代给的红利** | 恰好赶上的技术/制度/人口/国际格局窗口 |
| **时代给的劫难** | 恰好撞上的战争/灾荒/政策/市场崩塌 |
| **不可归因** | 运气、偶然事件、他人决策 |

**写法示例**：

> 他能在三个月内重建团队，**个人可控的部分**是：提前两个月就开始私下接触潜在成员。
> 但**时代红利**占更大比重：当时行业整体扩张，人才市场上没人问离职原因。
> **不可归因的部分**：他的核心客户在他重组期间恰好换了一位对接人。
> → 因此"他应对危机很强"这个结论，**不能直接推给用户**：
> 用户所处的环境没有"行业整体扩张"这个红利。

**这一步是防止本技能变成鸡汤的最后一道闸**。
