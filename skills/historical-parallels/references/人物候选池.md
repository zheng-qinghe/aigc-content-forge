# 人物候选池

> 用途：按处境原型索引中外人物，**避免每次检索都只命中那几个最著名的名字**。
> 每人标注：处境原型 / 结局类型（成败/中途/惨败/未竟）/ 主要史料线索。
> **不是名单，是检索起点** —— 最终选谁取决于用户具体处境。

---

## 使用规则

1. **每个处境至少取 3 人，且结局类型要分散**（必须有 1 个以上"非成功"结局）。
2. **中外各半**，并跨至少 2 个时代带。
3. **至少取 1 人权力位置与用户相反**（用户是决策者就取下属，用户是下属就取决策者）。
4. 本表是**起手式**，不是限制。表外的历史人物同样在候选范围内。

结局标记：✅善终成事 / ⚠️中途转向 / ❌彻底失败 / ⏳未竟而止

## 跨时代的"类型人物"

这些不是单一人物，而是可反复引用的**原型模式**（用于避免总找同一种人）：

| 类型 | 特征 | 中外例子 |
|---|---|---|
| **被贬谪而成就者** | 失去政治位置，作品在边缘大成 | 苏轼、王阳明、柳宗元、但丁、曼德拉 |
| **权力中途易手者** | 一度掌权后被清算 | 范蠡→张良、韩信、武则天晚年、海瑞、马克西米利安 |
| **抄家/破产后转向者** | 物质崩塌后转向非物质产出 | 曹雪芹、茨威格、卡夫卡、柳宗元 |
| **长期不被承认者** | 成果在生前被拒，死后封神 | 魏格、图灵、卡夫卡、沈括、埃马努埃莱二世（生前被革职） |
| **最大转变者** | 中年彻底转向 | 墨子、张载、李叔同、保罗（使徒） |
| **务实妥协者** | 放弃原则换存续，事后被骂 | 史可法、洪承畴、亨利·福特（对日本的绥靖争议） |
| **坚持到彻底失败者** | 判断可能对但时间不对 | 王安石变法、苏联改革者、T. S. Eliot |
| **被迫转行者** | 原路被封，改走邻道 | 巴菲特从纺织转投资、诺基亚从手机转网络 |

## 候选池使用示例

> **用户处境**：现金流断裂的共同创始人，被合伙人单方面稀释

检索选择：
- **同类处境**（共同创业/合伙人背叛）：雷·达利欧（桥水被控、被迫辞职）、
  华特·迪士尼（迪士尼十人帮内部分裂与控制权之争）、希尔顿家族（家族内斗）
- **权力位置相反**（下属视角）：被抛下的合伙人 = 楚共王（被大臣抛弃的君主）、
  勾践（臣子的极端隐忍）
- **非成功结局**（强制项）：通用电气 Jack Welch 的强制淘汰（决策后果由下属承担）
- **跨时代带**：古代取「太平天国后失败的大臣」、现代取「雷·达利欧」
